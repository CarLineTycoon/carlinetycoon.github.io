    Language (.clt-lang.json)¶

    A language file holds the game's texts in another language, one entry per text key. A key the file leaves out shows the English text, so a translation can grow a little at a time.

    Schema: language.schema.json · Example: example_language.zip

    Development builds only for now

    Every build of the game reads and checks language files, and the Mods page lists them. The language list in Options offers them in development builds of the game. Release builds do not list language mods yet.

    Example¶

    {
  "format": "car-line-tycoon.language",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "code": "en-GB",
  "name": "English (example)",
  "entries": [
    { "key": "front.mods", "value": "Mods and add-ons" },
    { "key": "mods.reload", "value": "Read the mod folder again" },
    { "key": "mods.open_folder", "value": "Show the mod folder" }
  ]
}

    Fields¶

    Field Type Required Description
    format string yes Always car-line-tycoon.language.
    formatVersion integer yes 1.
    gameVersion string no The game version that wrote the file. Informative.
    code string yes The language tag, such as pt-BR or uk: 2 to 12 letters, digits and hyphens.
    name string yes The language's own name, as the language list shows it: Português, Українська.
    font string no A TTF or OTF font file inside the mod folder, as a relative path such as fonts/MyFont.ttf.
    fontLicense string with font The font's licence, for example SIL Open Font License 1.1. Required when font is set.
    entries array of entries yes The texts, up to 20,000.

    Entry¶

    Field Type Required Description
    key string yes A key of the game's English text table, such as front.mods. Each key at most once in a file.
    value string yes The text in this language. Not empty.

    Keys and placeholders¶

    The game looks keys up without regard to letter case. Keys the game does not have are ignored.

    Some texts contain placeholders in braces, such as {file}, {count} or {path}. Keep every placeholder exactly as it is in English: the game replaces it with a value when it shows the text. A line break inside a text is written \n.

    In the game¶

    • A language mod that is active joins the language list in Options → Language and on the main menu, with its name and the share of the game's texts it covers, for example Português · 62%.
    • When the player picks it, the game shows the file's text for every key it has and the English text for the others.
    • When code is a language the game already lists, the mod fills that language. Any other code becomes a new entry in the list.

    Fonts¶

    The game checks the font and fontLicense fields: the path must stay inside the mod folder (no drive letter, no ..), and a font needs a licence. The game does not load the font file yet, so letters missing from the game's own font show as empty boxes.

    What the game checks¶

    • the header,
    • code is 2 to 12 letters, digits or hyphens, and name is not empty,
    • entries has at most 20,000 entries, each with a key and a value, and no key twice,
    • font, when set, is a relative path inside the mod folder and comes with a fontLicense.

    A language file can be up to 8 MB.
