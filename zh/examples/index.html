    示例模组¶

    example_lua_price 和 example_lua_counter 展示了普通价格请求 以及持续保存的销售计数。目前它们仅在开发版中运行，且初始为停用状态；有关启用方式和成就规则，请参见 Lua 指南。

    七个小型模组：五种文件格式各一个，另有两个带声音的模组。它们可在当前游戏版本中加载且不会出现警告；每次构建此网站时，都会使用游戏自带的读取器逐一检查。

    下载示例并解压到模组文件夹，然后在模组页面按重新加载即可试用。每个压缩包都包含一个模组文件夹。

    下载 类型 内容
    example_model.zip 车型 一辆小型敞篷汽车，包含所有部件和颜色，由游戏导出。可在设计方案页面导入。
    example_livery.zip 涂装 蓝色双色涂装，带有金属和镀铬漆面效果及锚形徽章。可在设计工作室的颜色方案中导入。
    example_layout.zip 布局 带围墙、分流器和传送带的生产厂房布局，适用于工厂底层。可通过建造 → 场地在场地的空置区域导入。
    example_scenario.zip 场景 “Corner Garage”：一条生产线、一个展厅和两个目标。可在新游戏 → 自由经营 → 场景中选择。
    example_language.zip 语言 以新的语言条目提供模组页面的三条文本。开发版中可在选项 → 语言中选择。
    example_audio.zip 声音（WAV） 用 WAV 文件制作的双音铃声，用作 research 提示音。参见声音。
    example_audio_ogg.zip 声音（OGG） 用 OGG Vorbis 文件制作的短促滴答声，用作 confirm 提示音。
    all-examples.zip 全部七个 将上述七个文件夹放在同一个压缩包中。

    示例内容¶

    example_livery/
  mod.json
  harbour_blue.clt-livery.json

    mod.json：

    {
  "format": "car-line-tycoon.mod",
  "formatVersion": 1,
  "gameVersion": ">=0.6.1",
  "id": "example_livery",
  "version": "1.0.0",
  "name": { "en": "Example livery: Harbour Blue" },
  "description": { "en": "A two-tone blue livery with a chrome trim, to import in the studio's colour schemes." },
  "authors": ["Car Line Tycoon modding docs"],
  "type": "livery"
}

    两个声音示例由正弦波制成，并以 CC0-1.0 许可发布，许可文本位于 license.txt。example_audio 中的内容如下：

    example_audio/
  mod.json
  license.txt
  audio/
    research_bell.wav

    试用方法：将文件夹复制到模组文件夹，按重新加载，在模组对应行按试听，启用模组，然后开始新游戏并完成一项研究（或在 OGG 示例中按下确认按钮）。停用模组后即可再次听到游戏自带的声音。

    基于示例制作模组¶

    1. 复制示例文件夹并为其指定新名称，例如 my_livery。
    2. 在 mod.json 中，将 id 设为相同名称，然后修改 name、description、authors 和 version。
    3. 重命名内容文件并修改其中的 id。
    4. 编辑各字段。每种格式的参考页面都会列出可修改的内容。
    5. 在模组页面按重新加载。如果该行变红，故障排查页面会说明警告原因。
