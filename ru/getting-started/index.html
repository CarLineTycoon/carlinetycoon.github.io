    Начало работы¶

    Авторы скриптов Lua могут воспользоваться руководством по разработке скриптов для API v1.

    Папка модов¶

    Игра загружает моды из одной папки на компьютере, расположенной рядом с сохранениями.

    Быстрее всего открыть её так: запустите игру, выберите Моды в главном меню, затем нажмите Открыть папку модов. Если папки ещё нет, игра создаст её и откроет в файловом менеджере.

    Папку также можно найти самостоятельно:

    Система Папка модов
    Windows %USERPROFILE%\AppData\LocalLow\DefaultCompany\Car Line Tycoon\Mods
    macOS ~/Library/Application Support/DefaultCompany/Car Line Tycoon/Mods
    Linux ~/.config/unity3d/DefaultCompany/Car Line Tycoon/Mods

    Как устроен мод¶

    В папке модов игра принимает три вида размещения модов.

    Папка мода с манифестом. Рекомендуемый вариант. Имя папки — это идентификатор мода, а mod.json содержит описание мода (см. Манифест):

    Mods/
  harbour_cars/
    mod.json
    models/
      harbour_coupe.clt-model.json
      harbour_van.clt-model.json

    Папка без манифеста. Игра читает все файлы модов внутри неё как единый набор с именем папки. Имя папки должно быть допустимым идентификатором.

    Отдельный файл. Файл, например harbour_blue.clt-livery.json, размещённый прямо в Mods/, считается отдельным модом. Его идентификатор — часть имени файла до .clt-.

    Для всех вариантов действуют общие правила:

    • Идентификаторы состоят из строчных латинских букв, цифр и символов подчёркивания, начинаются с буквы и имеют длину от 3 до 41 символа.
    • Игра ищет файлы модов не глубже трёх уровней папок внутри папки модов. Для организации можно использовать подпапки, например models/ или layouts/.
    • Игра определяет тип файла по расширению: .clt-model.json, .clt-livery.json, .clt-layout.json, .clt-scenario.json или .clt-lang.json. Остальные файлы игнорируются, кроме звуковых файлов (.wav и .ogg), объявленных в mod.json версии 2. См. раздел Звуки.
    • Символические ссылки и точки соединения пропускаются.
    • Папка exports принадлежит игре: туда попадают файлы, экспортированные из игры. Они отображаются в списках импорта, а страница «Моды» не показывает эту папку.

    Страница «Моды»¶

    Выберите Моды в главном меню. В строке каждого мода отображаются следующие элементы:

    • переключатель для включения и выключения мода,
    • название (на вашем языке, если оно указано в манифесте),
    • версия, авторы и тип,
    • красная рамка и красная строка предупреждения при проблеме (см. раздел Устранение неполадок),
    • для мода со звуками — кнопка Прослушать для каждого заменяемого сигнала и кнопка Подробности, если у мода есть ошибки или примечания.

    Игра считывает содержимое папки модов при каждом открытии главного меню. После изменения файла нажмите Перезагрузить, чтобы перечитать её. Моды перечислены в алфавитном порядке по английскому названию.

    Новый мод включён по умолчанию. Игра сохраняет выбранные настройки в mods.json рядом с папкой модов.

    Как игра использует моды¶

    Мод активен, если он включён и для него нет предупреждений. Активные моды появляются на страницах самой игры:

    Тип Где в игре
    Модель автомобиля Страница Проекты: команда Импортировать модель показывает файлы моделей; выберите файл, чтобы увидеть тот же предпросмотр, что и для вставленного проекта, затем импортируйте его как новую модель. Команда Экспортировать модель в сведениях о модели сохраняет файл в exports/<name>.clt-model.json.
    Ливрея Студия проектирования, Цветовые схемы: команда Импортировать ливрею добавляет файл как новую цветовую схему. Требуется исследование цветовых схем.
    Планировка Строительство → Площадки: команда Импортировать планировку размещает стены, зоны и объекты из файла; Экспортировать планировку сохраняет открытый этаж открытой площадки.
    Сценарий «Новая игра» → Свободная игра: в списке Сценарий сценарии активных модов показаны после официальных сценариев вместе с названием мода.
    Язык Настройки → Язык и список языков главного меню; рядом показана доля переведённых текстов. Пока доступно только в сборках для разработки.
    Звук Сигналы подтверждения и завершения исследования в игре. Звуки загружаются при чтении папки Mods главным меню; в играх, начатых или загруженных после этого, используются новые звуки.

    При запуске или загрузке игры активные моды записываются в сохранение: их идентификаторы, версии, типы и хеши файлов. В списке сохранений такие игры отмечены как с модами, а в меню паузы отображается Активные моды: N. Сохранение продолжит загружаться, даже если использованный в нём мод впоследствии удалён.

    Достижения¶

    Модели автомобилей, ливреи, планировки и языки не влияют на достижения.

    Для сценария из мода действует правило начала любой свободной игры: игра считается облегчённой и достижения не выдаются, если запуск выполнен на лёгкой сложности, с фиксированной суммой от $100 000 или с более чем одной готовой сборочной линией.

    Версии и совместимость¶

    Каждый файл мода начинается с трёх полей:

    • format: тип файла, например car-line-tycoon.livery.
    • formatVersion: версия формата. Пять форматов файлов с содержимым имеют версию 1. Манифест может иметь версию 1 или 2; версия 2 объявляет звуки.
    • gameVersion: версия игры, в которой создан файл. В файлах с содержимым игра игнорирует это поле.

    Игра читает файлы своей версии формата и более ранних версий. Для файла с более новой версией formatVersion появляется предупреждение Требуется более новая версия игры.

    В mod.json поле gameVersion имеет отдельное значение: минимальная версия игры, необходимая моду, записанная как "0.6.1" или ">=0.6.1". Если версия игры ниже, появляется то же предупреждение, и игра не использует мод.

    Неизвестные игре поля игнорируются. Можно добавлять в файл собственные заметки в виде дополнительных полей; файл для более новой версии также загрузится, если в нём добавлены только поля.

    0.6.1 и новее Импорт и экспорт моделей, ливрей и планировок; языковые моды в сборках для разработки
