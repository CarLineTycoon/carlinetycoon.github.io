    语言（.clt-lang.json）¶

    语言文件为游戏文本提供其他语言的译文，每个文本键对应一个条目。文件中未列出的键会显示英文，因此你可以逐步添加译文。

    架构：language.schema.json · 示例：example_language.zip

    目前仅限开发版

    游戏的每个版本都会读取并检查语言文件，模组页面也会列出这些文件。开发版中，选项的语言列表会显示这些语言模组。正式版暂时不会列出语言模组。

    示例¶

    {
  "format": "car-line-tycoon.language",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "code": "en-GB",
  "name": "English (example)",
  "entries": [
    { "key": "front.mods", "value": "Mods and add-ons" },
    { "key": "mods.reload", "value": "Read the mod folder again" },
    { "key": "mods.open_folder", "value": "Show the mod folder" }
  ]
}

    字段¶

    字段 类型 必需 说明
    format 字符串 是 固定为 car-line-tycoon.language。
    formatVersion 整数 是 1。
    gameVersion 字符串 否 生成文件的游戏版本，仅供参考。
    code 字符串 是 语言标签，例如 pt-BR 或 uk：长度为 2 至 12 个字母、数字和连字符。
    name 字符串 是 以该语言书写的名称，显示在语言列表中，例如 Português、Українська。
    font 字符串 否 模组文件夹中的 TTF 或 OTF 字体文件，使用相对路径，例如 fonts/MyFont.ttf。
    fontLicense 字符串 设置 font 时必需 字体的许可证，例如 SIL Open Font License 1.1。设置 font 时必填。
    entries 条目 数组 是 文本，最多 20,000 条。

    条目¶

    字段 类型 必需 说明
    key 字符串 是 游戏英文文本表中的键，例如 front.mods。每个文件中每个键最多出现一次。
    value 字符串 是 该语言的文本。不能为空。

    键与占位符¶

    游戏查找键时不区分大小写。游戏中不存在的键会被忽略。

    部分文本包含花括号占位符，例如 {file}、{count} 或 {path}。请保持每个占位符与英文完全一致：游戏显示文本时会将其替换为对应值。文本中的换行符写作 \n。

    在游戏中的显示¶

    • 活动语言模组会加入选项 → 语言和主菜单的语言列表，并显示其name及覆盖游戏文本的比例，例如 Português · 62%。
    • 玩家选择该语言后，游戏会对文件中包含的键显示对应文本，其余键显示英文。
    • 当 code是游戏已列出的语言时，模组会补充该语言。其他代码会在列表中创建新条目。

    字体¶

    游戏会检查 font 和 fontLicense 字段：路径必须位于模组文件夹内（不能包含盘符或 ..），字体必须附带许可证。游戏目前还不会加载字体文件，因此游戏自带字体缺少的字形会显示为空框。

    游戏检查的内容¶

    • 文件头，
    • code 长度为 2 至 12 个字母、数字或连字符，且 name 不为空，
    • entries 最多包含 20,000 条，每条均有键和值，且键不重复，
    • 设置 font 时，它必须是模组文件夹内的相对路径，并且还必须设置 fontLicense。

    语言文件最大为 8 MB。
