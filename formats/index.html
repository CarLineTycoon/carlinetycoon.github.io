    File formats¶

    Car Line Tycoon reads six kinds of JSON file. Five carry content, and the manifest describes a mod folder.

    File Extension or name Format id Reference Schema
    Manifest mod.json car-line-tycoon.mod Manifest manifest.schema.json
    Car model .clt-model.json car-line-tycoon.model Car model model.schema.json
    Livery .clt-livery.json car-line-tycoon.livery Livery livery.schema.json
    Layout .clt-layout.json car-line-tycoon.layout Layout layout.schema.json
    Scenario .clt-scenario.json car-line-tycoon.scenario Scenario scenario.schema.json
    Language .clt-lang.json car-line-tycoon.language Language language.schema.json

    The header¶

    Every file starts with the same three fields:

    Field Type Value
    format string The format id from the table above. A file with another value is refused.
    formatVersion integer 1. A higher number is refused with Requires a newer game version.
    gameVersion string The game version that wrote the file, for example "0.6.2". Content files: informative only. Manifest: the oldest game version the mod needs.

    Rules for every file¶

    • Encoding. Save files as UTF-8. A byte order mark at the start is fine.
    • Size. A file can be up to 2 MB. A language file can be up to 8 MB. A larger file gets the warning File too large.
    • Types. Write numbers as plain JSON numbers (4) and texts as JSON strings ("Harbour Blue"). A value of the wrong kind, such as a word where a number belongs, makes the file invalid.
    • Unknown fields. The game ignores fields it does not know, at the top level and inside lists.
    • Ids. An id uses lower-case letters a–z, digits and underscores, starts with a letter and is 3 to 41 characters long: ^[a-z][a-z0-9_]{2,40}$.
    • Data only. No format carries a mesh, a texture or a script. Parts, colours, emblems and objects are chosen among the game's own; the allowed values page lists them.

    When the game checks a file¶

    The game checks a file twice.

    1. When it reads the Mods folder. The game reads every file with its format reader. A file that is not JSON, has the wrong header, is too large or misses a required field gives the mod a warning, and the game does not use the mod. For a scenario the game also checks the objectives and the texts at this point.
    2. When you use the file in the game. Importing a model, a livery or a layout runs the game's own rules: parts must exist, colours must use the game's channels, objects must fit where they are placed. The reference page of each format says what the game checks at this step.

    JSON Schemas¶

    Each format has a JSON Schema (draft 2020-12), generated from the game's code. A schema checks the structure of a file and the allowed ids, so your editor can flag a typo before you start the game.

    Format Schema URL
    Manifest https://carlinetycoon.github.io/schemas/manifest.schema.json
    Car model https://carlinetycoon.github.io/schemas/model.schema.json
    Livery https://carlinetycoon.github.io/schemas/livery.schema.json
    Layout https://carlinetycoon.github.io/schemas/layout.schema.json
    Scenario https://carlinetycoon.github.io/schemas/scenario.schema.json
    Language https://carlinetycoon.github.io/schemas/language.schema.json

    In Visual Studio Code, add this to your settings to check every mod file as you type:

    {
  "json.schemas": [
    { "fileMatch": ["mod.json"], "url": "https://carlinetycoon.github.io/schemas/manifest.schema.json" },
    { "fileMatch": ["*.clt-model.json"], "url": "https://carlinetycoon.github.io/schemas/model.schema.json" },
    { "fileMatch": ["*.clt-livery.json"], "url": "https://carlinetycoon.github.io/schemas/livery.schema.json" },
    { "fileMatch": ["*.clt-layout.json"], "url": "https://carlinetycoon.github.io/schemas/layout.schema.json" },
    { "fileMatch": ["*.clt-scenario.json"], "url": "https://carlinetycoon.github.io/schemas/scenario.schema.json" },
    { "fileMatch": ["*.clt-lang.json"], "url": "https://carlinetycoon.github.io/schemas/language.schema.json" }
  ]
}

    A few rules are outside what a schema can say, such as the file size and the checks the game makes when you import a file. The reference pages list them.
