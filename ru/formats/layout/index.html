    Планировка (.clt-layout.json)¶

    Планировка содержит стены, зоны и объекты одного этажа на одной площадке. При импорте каждый элемент строится по обычной цене и по тем же правилам, что и при строительстве вручную.

    Схема: layout.schema.json · Пример: example_layout.zip

    Простой способ: экспорт из игры¶

    Откройте Строительство → Площадки, выберите площадку и этаж, затем нажмите Экспортировать планировку. Игра сохраняет файл в папке exports внутри папки модов. Имя файла соответствует площадке и этажу: industrial_1.clt-layout.json — первый этаж завода.

    Пример¶

    {
  "format": "car-line-tycoon.layout",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "id": "small_hall",
  "name": "Small hall",
  "site": "industrial",
  "floor": 0,
  "objects": [
    { "definition": "split", "x": 25, "z": 14, "rotation": "North" },
    { "definition": "belt", "x": 20, "z": 7, "rotation": "East" }
  ],
  "walls": [
    { "x1": 18, "z1": 5, "x2": 42, "z2": 5 },
    { "x1": 42, "z1": 5, "x2": 42, "z2": 35 },
    { "x1": 42, "z1": 35, "x2": 18, "z2": 35 },
    { "x1": 18, "z1": 35, "x2": 18, "z2": 5 }
  ],
  "areas": [
    { "kind": "Production", "x": 18, "z": 5, "width": 24, "depth": 30 }
  ]
}

    Поля¶

    Поле Тип Обязательно Описание
    format строка да Всегда car-line-tycoon.layout.
    formatVersion целое число да 1.
    gameVersion строка нет Версия игры, в которой был создан файл. Справочная информация.
    id строка да Идентификатор файла. Шаблон ^[a-z][a-z0-9_]{2,40}$.
    name строка нет Название планировки.
    site строка да industrial (завод) или urban (автосалон).
    floor целое число нет Этаж; 0 — первый этаж. У завода есть только этаж 0, у автосалона — этажи с 0 по 5. По умолчанию 0.
    objects массив объектов да Не более 5000. Может быть пустым.
    walls массив стен да Не более 5000. Может быть пустым.
    areas массив зон да Не более 5000. Может быть пустым.

    Позиции задаются ячейками строительной сетки площадки; размер одной ячейки — 2 метра. Экспортируйте планировку из игры, чтобы увидеть координаты своих цехов.

    Объект¶

    Поле Тип Обязательно Описание
    definition строка да Идентификатор объекта, например belt или split. См. раздел Объекты.
    x целое число да Ячейка объекта по оси x.
    z целое число да Ячейка объекта по оси z.
    fineX целое число нет Для отдельно стоящей мебели: смещение внутри ячейки в шестнадцатых долях ячейки, от 0 до 15.
    fineZ целое число нет То же смещение по оси z.
    rotation строка да North, East, South или West, без учёта регистра.

    Стена¶

    Прямая стена между двумя точками сетки.

    Поле Тип Обязательно Описание
    x1, z1 целое число да Начальная точка.
    x2, z2 целое число да Конечная точка.

    Зона¶

    Поле Тип Обязательно Описание
    kind строка да Production, Warehouse, Services, Yard, Commercial или Workshop, без учёта регистра.
    x, z целое число да Первая ячейка зоны.
    width целое число да Ширина в ячейках, от 1.
    depth целое число да Глубина в ячейках, от 1.

    Как импорт создаёт планировку¶

    Игра размещает элементы в следующем порядке на площадке и этаже, указанных в файле:

    1. Цех. Если стены образуют замкнутый прямоугольник, игра строит его как один цех тем же инструментом, что и прямоугольник Стена в меню строительства. Все четыре стены прямоугольника считаются размещёнными или пропущенными вместе.
    2. Внутренние стены. Каждая другая стена строится отдельно. Отдельная стена может находиться только внутри цеха.
    3. Зоны.
    4. Объекты.

    Каждый элемент оплачивается по обычной цене и подчиняется обычным правилам строительства. Если игра отклоняет элемент (ячейка занята, закончились деньги, объект неизвестен или требует исследования, либо площадка ещё вам не принадлежит), она пропускает этот элемент и продолжает импорт. По завершении игра показывает Планировка импортирована: размещено N, пропущено M.

    Для каждого файла планировки указывайте один цех. Если стены файла не образуют один замкнутый прямоугольник, охватывающий все стены, игра строит их как отдельные стены, а стены за пределами существующего цеха пропускаются.

    Что не входит в планировку¶

    Планировка содержит только постройки. Персонал, модели автомобилей, запасы, исследования и деньги в текущей игре остаются без изменений.

    Что игра проверяет при чтении файла¶

    • заголовок и id,
    • поле site присутствует, а значение floor неотрицательное,
    • поля objects, walls и areas присутствуют и содержат не более 5000 записей каждое,
    • у каждого объекта есть поле definition и известное игре значение rotation, а fineX/fineZ находятся в диапазоне от 0 до 15,
    • у каждой зоны есть известное игре значение kind и положительные значения width и depth.

    Остальные проверки выполняются отдельно для каждого элемента во время импорта.
