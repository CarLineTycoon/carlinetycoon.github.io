    Allowed values¶

    This page is generated from the game's code. It lists the ids the file formats accept in the current version.

    Colour channels¶

    Used by models and liveries. Each channel appears at most once in a list of colours.

    Channel Takes a finish other than normal
    body yes
    roof yes
    interior no
    trim yes
    chassis no
    wheels yes
    powertrain no
