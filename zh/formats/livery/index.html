    涂装（.clt-livery.json）¶

    涂装为汽车的每个颜色通道指定颜色和漆面效果，并包含一个徽章。在设计工作室中，按导入涂装会将其添加到当前车型，作为新的颜色方案。

    架构：livery.schema.json · 示例：example_livery.zip

    示例¶

    {
  "format": "car-line-tycoon.livery",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "id": "harbour_blue",
  "name": "Harbour Blue",
  "colors": [
    { "channel": "body", "value": "#2F5D8A", "finish": "metallic" },
    { "channel": "roof", "value": "#E8E1CF" },
    { "channel": "trim", "value": "#C4C6C7", "finish": "chrome" },
    { "channel": "wheels", "value": "#E8E1CF" },
    { "channel": "interior", "value": "#5A3E2E" }
  ],
  "emblem": {
    "shape": "shield",
    "pattern": "horizontal",
    "color1": "navy",
    "color2": "cream",
    "icon": "anchor",
    "iconColor": "gold",
    "mascotFinish": "chrome"
  }
}

    字段¶

    字段 类型 必需 说明
    format 字符串 是 固定为 car-line-tycoon.livery。
    formatVersion 整数 是 1。
    gameVersion 字符串 否 生成文件的游戏版本，仅供参考。
    id 字符串 是 文件 ID。格式为 ^[a-z][a-z0-9_]{2,40}$。
    name 字符串 否 设计工作室中的颜色方案名称。若为空，工作室会使用文件名。
    colors 颜色 数组 是 至少一种颜色；每个通道最多指定一次。
    emblem 徽章 是 完整的徽章数据。

    颜色¶

    字段 类型 必需 说明
    channel 字符串 是 body、roof、interior、trim、chassis、wheels 或 powertrain。
    value 字符串 是 #RRGGBB 或 #RRGGBBAA，使用十六进制表示。
    finish 字符串 否 normal、metallic、matte、pearl、flake 或 chrome，大小写不限。普通漆面可省略此字段。

    只有 body、roof、trim 和 wheels 支持普通以外的漆面效果。导入涂装时，省略的通道会使用设计工作室中的默认颜色。

    徽章¶

    七个字段都必填，且每个字段都必须使用游戏自带的值。允许的值页面列出了这些值。

    字段 类型 说明
    shape 字符串 徽章的形状，例如 shield 或 circle。
    pattern 字符串 徽章的图案，例如 plain 或 horizontal。
    color1 字符串 徽章的第一种颜色，取自徽章调色板（navy、cream 等）。
    color2 字符串 徽章的第二种颜色，取自徽章调色板。
    icon 字符串 徽章图标，例如 star 或 anchor。
    iconColor 字符串 图标的颜色，取自徽章调色板。
    mascotFinish 字符串 引擎盖立标的漆面效果：chrome 或 brass。

    注意

    设计工作室会导入涂装中的颜色。文件必须包含有效徽章才能加载，公司会保留自己的徽章。

    游戏检查的内容¶

    读取模组文件夹时，游戏会检查文件头、id、每种颜色是否包含通道和值以及有效漆面效果，并检查徽章是否使用游戏支持的值。

    在设计工作室导入涂装时，游戏会检查：

    • 每个通道都必须是上述七种之一，且每个通道最多出现一次，
    • 每个值必须是 #RRGGBB 或 #RRGGBBAA，
    • 普通以外的漆面效果只能用于 body、roof、trim 或 wheels。

    不符合这些检查的涂装会显示此涂装包含不支持的颜色。

    导入涂装需要先完成颜色方案研究，与设计工作室中的复制此方案相同。
