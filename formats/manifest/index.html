    Manifest (mod.json)¶

    mod.json sits at the top of a mod folder and tells the game what the mod is. The folder name must be the same as the mod's id.

    Schema: manifest.schema.json

    Example¶

    {
  "format": "car-line-tycoon.mod",
  "formatVersion": 1,
  "gameVersion": ">=0.6.1",
  "id": "harbour_cars",
  "version": "1.2.0",
  "name": { "en": "Harbour Cars", "it": "Auto del porto" },
  "description": { "en": "Two small cars and a blue livery." },
  "authors": ["Aria", "Tom"],
  "type": "pack"
}

    Fields¶

    Field Type Required Description
    format string yes Always car-line-tycoon.mod.
    formatVersion integer yes 1.
    gameVersion string no The oldest game version the mod needs: "0.6.1" or ">=0.6.1". The game compares it with its own version. Leave it out, or write a value the game cannot read, and the game does not check it.
    id string yes The mod's id. It must match the folder name. Pattern ^[a-z][a-z0-9_]{2,40}$.
    version string yes Your version of the mod, shown on the Mods page as v1.2.0. Any non-empty text.
    name object yes The mod's name per language: keys are two-letter codes such as "en", "it", "fr", "es", "de", values are texts. At least one entry.
    description object no The mod's description per language, in the same shape as name.
    authors array of strings no The authors. The Mods page joins them with commas.
    type string yes model, livery, layout, scenario, language or pack.

    How the type works¶

    • A mod of type model, livery, layout, scenario or language reads only the files of that type. Files of other types inside it are left alone.
    • A mod of type pack reads all five types.
    • A mod needs at least one file it can use. A mod folder with no usable file gets the warning The mod contains no usable files.

    Names and languages¶

    The Mods page shows the name in the player's language when name has it, then the English one, then the first one in the file. description works the same way. Use two-letter language codes: en, it, fr, es, de, ru, zh and so on.

    Rules¶

    • The folder name and id must be the same, otherwise the mod gets the warning Folder name does not match the ID in mod.json.
    • When a manifest cannot be read, or misses id, version, name or a valid type, the mod gets the warning Invalid file: mod.json.
    • A folder without mod.json works too: the game reads it as a pack named after the folder. Its folder name must then be a valid id, otherwise the warning is mod.json is missing or invalid.
    • When two mods have the same id, the game keeps the first one it finds.
