    清单文件（mod.json）¶

    mod.json位于模组文件夹顶层，用于告知游戏该模组的信息。文件夹名称必须与模组的 id 相同。

    架构：manifest.schema.json

    示例¶

    {
  "format": "car-line-tycoon.mod",
  "formatVersion": 1,
  "gameVersion": ">=0.6.1",
  "id": "harbour_cars",
  "version": "1.2.0",
  "name": { "en": "Harbour Cars", "it": "Auto del porto" },
  "description": { "en": "Two small cars and a blue livery." },
  "authors": ["Aria", "Tom"],
  "type": "pack"
}

    字段¶

    字段 类型 必需 说明
    format 字符串 是 固定为 car-line-tycoon.mod。
    formatVersion 整数 是 1。
    gameVersion 字符串 否 模组所需的最低游戏版本："0.6.1" 或 ">=0.6.1"。游戏会与自身版本进行比较。省略该字段，或填写游戏无法读取的值时，游戏不会进行版本检查。
    id 字符串 是 模组 ID，必须与文件夹名称一致。格式为 ^[a-z][a-z0-9_]{2,40}$。
    version 字符串 是 模组版本，在模组页面显示为 v1.2.0。可填写任何非空文本。
    name 对象 是 各语言对应的模组名称：键使用两字母语言代码，例如 "en"、"it"、"fr"、"es"、"de"；值为文本。至少需要一项。
    description 对象 否 各语言对应的模组说明，结构与 name 相同。
    authors 字符串数组 否 作者列表。模组页面会用逗号连接作者姓名。
    type 字符串 是 model、livery、layout、scenario、language 或 pack。

    类型的作用¶

    • 类型为 model、livery、layout、scenario 或 language 的模组只读取该类型的文件，其中其他类型的文件会被忽略。
    • 类型为 pack 的模组会读取全部五种类型。
    • 模组至少需要包含一个可用文件。模组文件夹没有可用文件时，会显示警告该模组没有可用文件。

    名称和语言¶

    如果 name 包含玩家当前语言的名称，模组页面会优先显示该名称；否则显示英文名称，再否则显示文件中的第一项。description采用相同规则。语言代码使用两个字母，例如 en、it、fr、es、de、ru、zh等。

    规则¶

    • 文件夹名称必须与 id 相同，否则模组会显示警告文件夹名称与 mod.json 中的 ID 不一致。
    • 清单文件无法读取，或缺少 id、version、name 或有效的 type 时，模组会显示警告无效文件：mod.json。
    • 文件夹也可以不包含 mod.json：游戏会将其作为以文件夹命名的 pack 读取。此时，文件夹名称必须符合有效 ID 格式，否则会显示警告mod.json 缺失或无效。
    • 两个模组的 ID 相同时，游戏会保留先找到的模组。
