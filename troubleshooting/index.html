    Troubleshooting¶

    When something is wrong with a mod, its row on the Mods page gets a red border and one red warning line. The game does not use the mod until the problem is fixed, whatever the position of its switch. The game shows one warning per mod, for the first problem it finds; after a fix, press Reload to see whether another one follows.

    Warnings on the Mods page¶

    Invalid file: file name¶

    The game could not read the file, or the file is incomplete. Check, in this order:

    1. Is it valid JSON? A missing comma, an extra comma before } or ], or a missing quote is enough. A JSON validator or an editor with the JSON Schemas points to the line.
    2. Is the header right? format must match the file type exactly (car-line-tycoon.livery for a .clt-livery.json file), and formatVersion must be 1.
    3. Are the types right? Numbers are plain numbers (4), texts are in quotes ("Harbour Blue"), true and false have no quotes, and lists are in square brackets. A word where a number belongs makes the file invalid.
    4. Are the required fields there? Each reference page marks them. The most common misses: id, an empty parts list in a model, objects/walls/areas in a layout (write [] when they are empty), texts in a scenario.
    5. Are the values allowed? An id with capital letters or spaces, an emblem colour outside the palette, an area kind the game does not have, a scenario objective that is not a Free play objective. The allowed values page lists them.

    When the warning names mod.json, the problem is in the manifest. See Manifest.

    Requires a newer game version¶

    Either the mod's mod.json asks for a newer game in gameVersion, or one of its files has a formatVersion above 1. Update the game, or lower the version in the mod if it was set by mistake.

    File too large: file name¶

    A mod file can be up to 2 MB, and a language file up to 8 MB. Split a large mod into several files, for example one model per file.

    mod.json is missing or invalid¶

    A folder in the Mods folder has no mod.json, and its name is not a valid id, so the game cannot use it as a pack. Add a mod.json, or rename the folder with lower-case letters, digits and underscores (3 to 41 characters, starting with a letter).

    Folder name does not match the ID in mod.json¶

    The folder's name and the id in its mod.json must be the same text. Rename one of them.

    The mod contains no usable files¶

    The game found no file it can use in the mod. Check that:

    • the files end in .clt-model.json, .clt-livery.json, .clt-layout.json, .clt-scenario.json or .clt-lang.json,
    • the file types match the manifest's type (a livery mod reads only livery files; use pack for several types),
    • the files are at most three folder levels below the mod folder.

    Messages during import¶

    Message Where What to do
    No files of this type in the mod folder. An import list No active mod has a file of this type. Check that the mod is switched on and has no warning, then press Reload on the Mods page.
    This livery contains unsupported colours. Studio, Import livery A colour uses an unknown channel, a channel twice, a value that is not #RRGGBB or #RRGGBBAA, or a finish on a channel that takes none. See Livery.
    Layout imported: N placed, M skipped Build → Sites Skipped pieces were refused by the building rules: the cell is taken, the money ran out, the object needs research, or the site is not yours yet. See Layout.
    Could not save to path Any export The game could not write in the exports folder. Check that the disk has space and the folder is writable.

    When an imported model shows a problem in its preview, the same message appears as for a pasted design: a part the catalogue does not have, parts that do not fit together, or colours the game does not accept. See Car model.

    My mod does not show up at all¶

    • The file or folder must sit directly in the Mods folder: Mods/my_mod/mod.json or Mods/my_file.clt-livery.json. A mod one folder deeper, such as Mods/downloads/my_mod/, is read as a mod called downloads.
    • The game reads the folder when the main menu opens. Press Reload after a change.
    • Folders and files that are symbolic links or junctions are skipped. Copy the real files into the Mods folder.
    • Make sure you are looking in the right folder: Open mod folder on the Mods page opens it.

    My scenario is not in the list¶

    A scenario shows up in New game → Free play → Scenario when its mod is switched on and has no warning. Scenarios of mods come after the three official ones.

    When the game refuses to start a scenario, check startChapter: it must be empty or one of the story chapters.
