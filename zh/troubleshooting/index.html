    故障排查¶

    Lua 限制与错误页面介绍脚本诊断信息和重置行为。

    模组出现问题时，其在模组页面上的条目会显示红色边框和一行红色警告。问题解决前，游戏不会使用该模组，无论开关处于什么位置。游戏会为每个模组显示它发现的第一个问题对应的警告；修复后按重新加载，即可查看是否还有其他问题。

    模组页面上的警告¶

    无效文件：文件名¶

    游戏无法读取该文件，或文件内容不完整。请按以下顺序检查：

    1. JSON 格式是否有效？缺少逗号、在 } 或 ] 前多出逗号，或缺少引号，都会导致错误。JSON 验证器或支持 JSON Schema 的编辑器可以指出错误行。
    2. 文件头是否正确？format必须与文件类型完全一致（.clt-livery.json文件应填写 car-line-tycoon.livery），formatVersion必须为 1。
    3. 字段类型是否正确？数字应为普通数字（4），文本应加引号（"Harbour Blue"），true和false不加引号，列表应使用方括号。数字字段填写单词会使文件无效。
    4. 必需字段是否齐全？每个格式的参考页面都会标明必需字段。最常见的缺失项：id、车型文件中的空parts列表、布局中的objects／walls／areas（为空时填写 []），以及场景中的texts。
    5. 字段值是否允许？例如，id包含大写字母或空格、徽章颜色不在调色板内、区域kind不是游戏支持的值，或场景目标不是自由经营目标。允许的值页面列出了可用值。

    当警告提到 mod.json 时，问题出在清单文件中。请参阅清单文件。

    需要更新的游戏版本¶

    模组的 mod.json 中的 gameVersion 要求的游戏版本高于当前版本，或者其中一个文件的 formatVersion 高于 1。请更新游戏；如果模组中的版本填写有误，请将其调低。

    文件过大：文件名¶

    模组文件最大为 2 MB，语言文件最大为 8 MB。可将大型模组拆分为多个文件，例如每个车型单独使用一个文件。

    此游戏版本缺少所需功能：capability¶

    版本 2 的 mod.json 在 requires 中列出了此游戏不支持的功能，例如较新版本添加的功能。游戏会停用整个模组。请更新游戏；如果模组不需要该功能，也可以从 requires 中移除它。

    文件被拒绝：file（code，实际 value，上限 limit）¶

    版本 2 清单文件声明的文件未通过检查。对应行会显示首个错误，详情最多列出 20 条。声音页面解释了所有错误代码。常见原因包括：WAV 文件不是 16 位 PCM、采样率不是 22050、44100 或 48000 Hz、声音超过 5 秒、路径含大写字母，或清单文件声明的文件不存在于文件夹中。修复文件后按重新加载，并检查后续是否还有错误。所有错误清除前，模组会保持停用。

    其他文件夹中有相同 ID：folder。模组已停用。¶

    游戏的两个模组根目录中各有一个模组文件夹，分别包含 id 相同的版本 2 模组。游戏会同时停用这两个模组。请移除其中一个。

    已启用模组的文件已达到数据上限¶

    已启用模组声明的文件总量超过游戏限制（总计 512 MiB，含文件的模组最多 32 个）。按 ID 排序靠后的模组会保持停用。请停用或移除另一个模组，下一个模组便会启用。

    mod.json 缺失或无效¶

    模组文件夹中的一个文件夹没有 mod.json，且名称不符合有效 ID 格式，因此游戏无法将其作为合集使用。请添加 mod.json，或将文件夹重命名为仅含小写字母、数字和下划线的名称（3 至 41 个字符，并以字母开头）。

    文件夹名称与 mod.json 中的 ID 不一致¶

    文件夹名称必须与其 mod.json 中的 id 完全相同。请重命名其中一项。

    该模组没有可用文件¶

    游戏没有在该模组中找到可用文件。请检查以下内容：

    • 文件以 .clt-model.json、.clt-livery.json、.clt-layout.json、.clt-scenario.json 或 .clt-lang.json 结尾，
    • 文件类型与清单文件中的 type 匹配（livery模组只读取涂装文件；需要多种类型时请使用 pack），
    • 文件位于模组文件夹下三层以内。

    导入时的提示¶

    提示 位置 处理方法
    模组文件夹中没有此类型的文件。 导入列表 没有活动模组包含此类型的文件。请确认模组已启用且没有警告，然后在模组页面按重新加载。
    此涂装包含不支持的颜色。 设计工作室、导入涂装 颜色使用了未知颜色通道、重复通道、非 #RRGGBB 或 #RRGGBBAA 的值，或在不支持漆面效果的通道上设置了漆面效果。请参阅涂装。
    布局已导入：已放置 N 个，已跳过 M 个 建造 → 场地 建造规则拒绝了被跳过的部件：该格已被占用、资金不足、对象需要先完成相应研究，或该场地尚未归你所有。请参阅布局。
    无法保存到 路径 任意导出操作 游戏无法写入 exports 文件夹。请检查磁盘空间以及文件夹的写入权限。

    导入车型的预览出现问题时，会显示与粘贴设计相同的提示，例如目录中没有该部件、部件无法组合，或颜色不受游戏支持。请参阅车型。

    完全看不到我的模组¶

    • 文件或文件夹必须直接放在模组文件夹中：Mods/my_mod/mod.json或Mods/my_file.clt-livery.json。若模组又嵌套一层，例如Mods/downloads/my_mod/，游戏会将其读取为名为downloads的模组。
    • 主菜单打开时，游戏会读取模组文件夹。修改后请按重新加载。
    • 符号链接和目录联接形式的文件夹及文件会被跳过。请将实际文件复制到模组文件夹中。
    • 确认你查看的是正确的文件夹：模组页面上的打开模组文件夹可以打开该文件夹。

    声音没有播放¶

    • 确认模组已启用且对应行不是红色。模组页面上的试听会按音效音量播放声音；游戏静音或窗口未获得焦点时不会播放。
    • 更改后开始或载入的游戏会使用新声音。已打开的游戏会继续使用启动时载入的声音。
    • 两个启用的模组绑定同一提示音时，两者都会显示注意事项，游戏会播放自带声音。请停用其中一个模组。
    • 声音过响时，游戏会降低音量。对应行的注意事项会显示降低幅度。
    • 如果模组似乎已加载，但对应行随后显示 asset_decode，说明游戏无法解码该文件。在重启游戏或修改其文件之前，模组会保持停用。

    我的场景没有出现在列表中¶

    模组已启用且没有警告时，其场景会显示在新游戏 → 自由经营 → 场景中。模组场景排在三个官方场景之后。

    游戏拒绝启动场景时，请检查 startChapter：该字段必须为空或填写一个剧情章节。
