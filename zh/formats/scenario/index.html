    场景（.clt-scenario.json）¶

    场景提供带有独立目标的自由经营开局。它可以设定启动资金、已准备好的工厂和展厅、目标，以及可选的剧情章节、已完成的研究和一条特殊规则。游戏的三个官方场景也使用此格式，并由同一个读取器读取。

    架构：scenario.schema.json · 示例：example_scenario.zip

    示例¶

    {
  "format": "car-line-tycoon.scenario",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "id": "corner_garage",
  "startingFundsCents": 0,
  "readyLines": 1,
  "readyShowroom": true,
  "objectives": ["sales_100", "reputation_60"],
  "startChapter": "",
  "completedResearch": [],
  "rule": "",
  "texts": [
    {
      "lang": "en",
      "title": "Corner Garage",
      "description": "One assembly line and a small showroom. Sell a hundred cars and earn a good name in town."
    }
  ]
}

    字段¶

    字段 类型 必需 说明
    format 字符串 是 固定为 car-line-tycoon.scenario。
    formatVersion 整数 是 1。
    gameVersion 字符串 否 生成文件的游戏版本，仅供参考。
    id 字符串 是 场景 ID。格式为 ^[a-z][a-z0-9_]{2,40}$。在游戏中会变为 <mod id>.<scenario id>，例如 example_scenario.corner_garage。
    startingFundsCents 整数 否 启动资金，以美分计：4000000代表 40,000 美元。0会根据所选难度使用自由经营的标准资金。默认值为 0。
    readyLines 整数 是 已准备好的工厂中的生产线数量，范围为 1 至 4。
    readyShowroom 布尔值 否 设为 true 时，开局会提供已准备好的展厅。默认值为 false。
    objectives 字符串数组 是 游戏自由经营目标中的目标，数量为 1 至 40 个。
    startChapter 字符串 否 第一天发布的剧情章节，例如 tensions；留空则填写 ""。参见剧情章节。
    completedResearch 字符串数组 否 开局时已完成的研究主题，最多 40 项。游戏会自动完成这些主题所需的前置研究。参见研究主题。
    rule 字符串 否 可填写 daily_fleet_orders；无特殊规则时填写 ""。
    texts 文本 数组 是 各语言的标题和说明。至少需要一项。

    文本¶

    字段 类型 必需 说明
    lang 字符串 是 两字母语言代码，例如 en、it、fr、es、de 等。
    title 字符串 是 场景选择器中显示的场景标题。
    description 字符串 否 场景工具提示中的说明，显示在模组名称和目标上方。

    游戏会优先显示玩家所用语言的文本；若无对应文本，则显示英文文本；若也无英文文本，则显示文件中的第一项文本。

    特殊规则¶

    场景可以添加一条游戏支持的特殊规则：

    规则 作用
    daily_fleet_orders 只要订单栏位空闲，每天就会送来一份订购六辆汽车的车队订单。官方场景车队使用此规则。

    场景如何启动游戏¶

    1. 玩家在新游戏 → 自由经营 → 场景中选择场景。场景设定开局状态：已准备好的工厂及其 readyLines 条生产线、readyShowroom为true时的展厅，以及启动资金。玩家仍需选择难度。
    2. 游戏开始时，会完成 completedResearch 中的研究主题及其所有前置研究。游戏不认识的 ID 会被忽略。
    3. 设置 startChapter 后，游戏会在第一天发布该章节及之前的所有章节。
    4. 游戏目标由场景的 objectives 决定。

    场景 ID 会保存在存档中。之后移除模组，存档仍然可以加载并继续游玩。

    成就¶

    模组场景遵循所有自由经营开局的规则。如果以简单难度开始、startingFundsCents达到或超过 10000000（100,000 美元），或 readyLines大于 1，游戏会将其标记为辅助模式，且不会获得成就。

    游戏检查的内容¶

    读取模组文件夹时，游戏会检查：

    • 文件头和 id，
    • startingFundsCents 大于或等于 0，且 readyLines 在 1 至 4 之间，
    • rule 为空或为 daily_fleet_orders，
    • objectives 包含 1 至 40 项，且每项均不为空，每项都是游戏中的自由经营目标，
    • completedResearch 最多包含 40 项，且每项均不为空，
    • texts 至少包含一项，且每项都有 lang 和 title。

    游戏开始时，未知的 startChapter 会阻止游戏启动。请使用一个剧情章节，或将其留空。
