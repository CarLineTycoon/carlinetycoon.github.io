    Scenario (.clt-scenario.json)¶

    A scenario is a Free play start with its own goals. It sets the starting money, the ready factory and showroom, the objectives, and optionally a story chapter, research already done and one special rule. The game's three official scenarios are written in this same format and read by the same reader.

    Schema: scenario.schema.json · Example: example_scenario.zip

    Example¶

    {
  "format": "car-line-tycoon.scenario",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "id": "corner_garage",
  "startingFundsCents": 0,
  "readyLines": 1,
  "readyShowroom": true,
  "objectives": ["sales_100", "reputation_60"],
  "startChapter": "",
  "completedResearch": [],
  "rule": "",
  "texts": [
    {
      "lang": "en",
      "title": "Corner Garage",
      "description": "One assembly line and a small showroom. Sell a hundred cars and earn a good name in town."
    }
  ]
}

    Fields¶

    Field Type Required Description
    format string yes Always car-line-tycoon.scenario.
    formatVersion integer yes 1.
    gameVersion string no The game version that wrote the file. Informative.
    id string yes The scenario's id. Pattern ^[a-z][a-z0-9_]{2,40}$. In the game it becomes <mod id>.<scenario id>, for example example_scenario.corner_garage.
    startingFundsCents integer no The starting money in cents: 4000000 is $40,000. 0 gives the standard Free play money for the chosen difficulty. Default 0.
    readyLines integer yes Assembly lines in the ready factory, 1 to 4.
    readyShowroom boolean no true to start with a ready showroom. Default false.
    objectives array of strings yes The goals, 1 to 40, from the game's Free play objectives.
    startChapter string no A story chapter published on day one, such as tensions, or "" for none. See story chapters.
    completedResearch array of strings no Research topics done from the start, up to 40. The game adds the topics each of them needs. See research topics.
    rule string no daily_fleet_orders or "" for none.
    texts array of texts yes The title and description per language. At least one.

    Text¶

    Field Type Required Description
    lang string yes A two-letter language code: en, it, fr, es, de, ...
    title string yes The scenario's title in the Scenario selector.
    description string no The description in the scenario's tooltip, above the mod's name and the goals.

    The game shows the text of the player's language, then the English one, then the first one in the file.

    The rule¶

    A scenario can add one rule the game knows:

    Rule What it does
    daily_fleet_orders A fleet order of six cars arrives every day the order slot is free. The official scenario Fleets uses it.

    How the scenario starts a game¶

    1. The player picks the scenario in New game → Free play → Scenario. The scenario sets the start: the ready factory with readyLines lines, the showroom when readyShowroom is true, and the money. The player still picks the difficulty.
    2. When the game starts, the research topics in completedResearch are done, with every topic they need first. Ids the game does not know are ignored.
    3. When startChapter is set, the game publishes that chapter, and the chapters before it, on day one.
    4. The goals of the game are the scenario's objectives.

    The scenario's id is kept in the save. When the mod is later removed, the save still loads and plays on.

    Achievements¶

    A scenario from a mod follows the rule of every Free play start. The game counts as assisted, and earns no achievements, when it starts on Easy, with startingFundsCents of 10000000 ($100,000) or more, or with readyLines above 1.

    What the game checks¶

    When it reads the Mods folder:

    • the header and the id,
    • startingFundsCents is 0 or more and readyLines is between 1 and 4,
    • rule is empty or daily_fleet_orders,
    • objectives has 1 to 40 entries, none empty, and every one is a Free play objective of the game,
    • completedResearch has at most 40 entries, none empty,
    • texts has at least one entry, each with a lang and a title.

    When the game starts: an unknown startChapter stops the game from starting. Use one of the story chapters or leave it empty.
