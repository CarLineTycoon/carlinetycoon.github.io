    文件格式¶

    Car Line Tycoon 会读取六种 JSON 文件。五种文件包含游戏内容，清单文件用于描述模组文件夹。

    文件 扩展名或名称 格式 ID 参考文档 架构
    清单文件 mod.json car-line-tycoon.mod 清单文件 manifest.schema.json
    车型 .clt-model.json car-line-tycoon.model 车型 model.schema.json
    涂装 .clt-livery.json car-line-tycoon.livery 涂装 livery.schema.json
    布局 .clt-layout.json car-line-tycoon.layout 布局 layout.schema.json
    场景 .clt-scenario.json car-line-tycoon.scenario 场景 scenario.schema.json
    语言 .clt-lang.json car-line-tycoon.language 语言 language.schema.json

    文件头¶

    每个文件都以相同的三个字段开头：

    字段 类型 值
    format 字符串 上表中的格式 ID。其他值会导致文件被拒绝。
    formatVersion 整数 五种内容格式使用 1。清单文件可以使用 2（参见清单文件）。更高的数字会导致文件被拒绝，并显示需要更新的游戏版本。
    gameVersion 字符串 生成文件时的游戏版本，例如 "0.6.2"。内容文件：仅供参考。清单文件：模组所需的最低游戏版本。

    通用文件规则¶

    • 编码。使用 UTF-8 保存文件。文件开头可以带字节顺序标记。
    • 大小。文件最大为 2 MB，语言文件最大为 8 MB。超出限制会显示文件过大警告。
    • 类型。数字应使用普通 JSON 数字（4），文本应使用 JSON 字符串（"Harbour Blue"）。值的类型错误（例如数字字段填写单词）会导致文件无效。
    • 未知字段。游戏会忽略不认识的字段，包括顶层字段和列表中的字段。
    • ID。id使用小写字母 a–z、数字和下划线，以字母开头，长度为 3 至 41 个字符：^[a-z][a-z0-9_]{2,40}$。
    • 仅含数据。任何格式都不包含网格、纹理或脚本。部件、颜色、徽章和对象从游戏自带内容中选择；允许的值页面列出了这些内容。声音文件是唯一的二进制文件类型，且仅限版本 2 清单文件声明时使用（声音）。

    游戏何时检查文件¶

    游戏会检查文件两次。

    1. 读取模组文件夹时。游戏会使用对应格式的读取器检查每个文件。文件不是有效 JSON、文件头错误、文件过大或缺少必需字段时，模组会显示警告，游戏也不会使用该模组。此时游戏还会检查场景目标和文本。
    2. 在游戏中使用文件时。导入车型、涂装或布局时，游戏会应用自身规则：部件必须存在，颜色必须使用游戏支持的通道，对象必须适用于放置位置。每种格式的参考页面都会说明此步骤中的检查项目。

    JSON Schema¶

    每种格式都有一个 JSON Schema（draft 2020-12），由游戏代码生成。架构会检查文件结构和允许的 ID，编辑器可以在启动游戏前标记拼写错误。

    格式 架构 URL
    清单文件 https://carlinetycoon.github.io/schemas/manifest.schema.json
    车型 https://carlinetycoon.github.io/schemas/model.schema.json
    涂装 https://carlinetycoon.github.io/schemas/livery.schema.json
    布局 https://carlinetycoon.github.io/schemas/layout.schema.json
    场景 https://carlinetycoon.github.io/schemas/scenario.schema.json
    语言 https://carlinetycoon.github.io/schemas/language.schema.json

    在 Visual Studio Code 中，将以下内容添加到设置，即可在输入时检查每个模组文件：

    {
  "json.schemas": [
    { "fileMatch": ["mod.json"], "url": "https://carlinetycoon.github.io/schemas/manifest.schema.json" },
    { "fileMatch": ["*.clt-model.json"], "url": "https://carlinetycoon.github.io/schemas/model.schema.json" },
    { "fileMatch": ["*.clt-livery.json"], "url": "https://carlinetycoon.github.io/schemas/livery.schema.json" },
    { "fileMatch": ["*.clt-layout.json"], "url": "https://carlinetycoon.github.io/schemas/layout.schema.json" },
    { "fileMatch": ["*.clt-scenario.json"], "url": "https://carlinetycoon.github.io/schemas/scenario.schema.json" },
    { "fileMatch": ["*.clt-lang.json"], "url": "https://carlinetycoon.github.io/schemas/language.schema.json" }
  ]
}

    有些规则无法通过架构表达，例如文件大小以及导入文件时游戏执行的检查。参考页面会列出这些规则。
