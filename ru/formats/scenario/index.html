    Сценарий (.clt-scenario.json)¶

    Сценарий задаёт начало свободной игры с собственными целями. В нём указываются начальные деньги, готовые завод и автосалон, цели, а также необязательные сюжетная глава, завершённые исследования и особое правило. Три официальных сценария игры записаны в этом формате и обрабатываются тем же средством чтения.

    Схема: scenario.schema.json · Пример: example_scenario.zip

    Пример¶

    {
  "format": "car-line-tycoon.scenario",
  "formatVersion": 1,
  "gameVersion": "0.6.0",
  "id": "corner_garage",
  "startingFundsCents": 0,
  "readyLines": 1,
  "readyShowroom": true,
  "objectives": ["sales_100", "reputation_60"],
  "startChapter": "",
  "completedResearch": [],
  "rule": "",
  "texts": [
    {
      "lang": "en",
      "title": "Corner Garage",
      "description": "One assembly line and a small showroom. Sell a hundred cars and earn a good name in town."
    }
  ]
}

    Поля¶

    Поле Тип Обязательно Описание
    format строка да Всегда car-line-tycoon.scenario.
    formatVersion целое число да 1.
    gameVersion строка нет Версия игры, в которой был создан файл. Справочная информация.
    id строка да Идентификатор сценария. Шаблон ^[a-z][a-z0-9_]{2,40}$. В игре он становится <mod id>.<scenario id>, например example_scenario.corner_garage.
    startingFundsCents целое число нет Начальные деньги в центах: 4000000 — это $40 000. Значение 0 задаёт обычную сумму для свободной игры с выбранной сложностью. По умолчанию 0.
    readyLines целое число да Число сборочных линий на готовом заводе, от 1 до 4.
    readyShowroom логическое значение нет true — начать с готовым автосалоном. По умолчанию false.
    objectives массив строк да Игровые цели (от 1 до 40) из списка целей свободной игры.
    startChapter строка нет Сюжетная глава, открываемая в первый день, например tensions; значение "" означает отсутствие главы. См. раздел Сюжетные главы.
    completedResearch массив строк нет Исследования, завершённые в начале игры, не более 40. Игра добавляет необходимые для них исследования. См. раздел Исследования.
    rule строка нет daily_fleet_orders; значение "" означает отсутствие правила.
    texts массив текстов да Название и описание для каждого языка. Нужна хотя бы одна запись.

    Текст¶

    Поле Тип Обязательно Описание
    lang строка да Двухбуквенный код языка: en, it, fr, es, de и другие.
    title строка да Название сценария в селекторе Сценарий.
    description строка нет Описание во всплывающей подсказке сценария, над названием мода и целями.

    Игра показывает текст на языке игрока. Если такого текста нет, используется английский текст; если нет и английского, используется первый текст в файле.

    Правило¶

    Сценарию можно добавить одно известное игре правило:

    Правило Действие
    daily_fleet_orders Каждый день, когда слот заказа свободен, поступает заказ автопарка на шесть автомобилей. Это правило используется в официальном сценарии Автопарки.

    Как сценарий начинает игру¶

    1. Игрок выбирает сценарий в меню «Новая игра» → Свободная игра → Сценарий. Сценарий задаёт старт: готовый завод с числом линий, указанным в readyLines, автосалон при значении readyShowroom = true и начальные деньги. Сложность по-прежнему выбирает игрок.
    2. При запуске игры выполняются исследования из completedResearch вместе со всеми необходимыми предварительными исследованиями. Неизвестные игре идентификаторы игнорируются.
    3. Если задано startChapter, в первый день открываются эта глава и все предыдущие.
    4. Цели игры берутся из objectives сценария.

    Идентификатор сценария сохраняется в файле сохранения. Если позже удалить мод, сохранение продолжит загружаться и работать.

    Достижения¶

    Для сценария из мода действуют правила любого начала свободной игры. Игра считается облегчённой и достижения не выдаются, если она начинается на лёгкой сложности, с startingFundsCents не меньше 10000000 ($100 000) или с числом readyLines больше 1.

    Что проверяет игра¶

    При чтении папки модов проверяются:

    • заголовок и поле id,
    • startingFundsCents не меньше 0, а readyLines находится в диапазоне от 1 до 4,
    • rule пустое или равно daily_fleet_orders,
    • в objectives от 1 до 40 непустых значений, каждое из которых является целью свободной игры,
    • в completedResearch не более 40 непустых значений,
    • в texts есть хотя бы одна запись; в каждой указаны lang и title.

    При запуске игры неизвестное значение startChapter не позволит начать игру. Используйте одну из сюжетных глав или оставьте поле пустым.
