    Модель автомобиля (.clt-model.json)¶

    Файл модели автомобиля содержит проект из студии: детали, цвета, цветовые схемы и комплекты опций. При импорте файла игра рассчитывает все остальные параметры (цену, характеристики и время производства) по собственному каталогу, поэтому файл модели не может содержать собственные числовые значения.

    Схема: model.schema.json · Пример: example_model.zip

    Простой способ: экспорт из игры¶

    Откройте страницу Проекты, выберите модель и нажмите Экспортировать модель в её сведениях. Игра создаст файл exports/<model_name>.clt-model.json в папке модов (имя модели в нижнем регистре, слова разделены символами подчёркивания) и покажет путь. Скопируйте этот файл в папку своего мода и редактируйте его там.

    Пример¶

    Сокращённый файл (в экспортированном файле перечислены все детали и все семь цветовых каналов):

    {
  "format": "car-line-tycoon.model",
  "formatVersion": 1,
  "gameVersion": "0.6.2",
  "id": "harbour_coupe",
  "name": "Harbour Coupe",
  "parts": [
    { "category": "body", "part": "Body_Taxi" },
    { "category": "bonnet", "part": "Bonnet_Taxi" },
    { "category": "chassis", "part": "Chassis_T_Wider" },
    { "category": "wheels", "part": "Wheel_Taxi_Stamp" },
    { "category": "motor", "part": "Motor_Bucket" }
  ],
  "colors": [
    { "channel": "body", "value": "#2F5D8A", "finish": 1 },
    { "channel": "trim", "value": "#C4C6C7" }
  ],
  "schemes": [
    {
      "id": "default",
      "name": "",
      "colors": [
        { "channel": "body", "value": "#2F5D8A", "finish": 1 },
        { "channel": "trim", "value": "#C4C6C7" }
      ]
    }
  ]
}

    Поля¶

    Поле Тип Обязательно Описание
    format строка да Всегда car-line-tycoon.model.
    formatVersion целое число да 1.
    gameVersion строка нет Версия игры, в которой был создан файл. Справочная информация.
    id строка да Идентификатор файла. Шаблон ^[a-z][a-z0-9_]{2,40}$.
    name строка нет Название модели. При импорте оно становится названием новой модели.
    parts массив деталей да Детали автомобиля, по одной на категорию. Нужна хотя бы одна.
    colors массив цветов нет Цвета модели по умолчанию, не более одного на канал.
    schemes массив схем нет Цветовые схемы модели.
    packages массив комплектов нет Комплекты опций (двигатель, броня, вооружение).

    Деталь¶

    Поле Тип Обязательно Описание
    category строка да Категория детали, например body, wheels или motor. См. раздел Категории деталей.
    part строка да Идентификатор детали в игровом каталоге.

    В каталоге несколько сотен деталей; студия знает, какие из них совместимы. Соберите автомобиль в студии, экспортируйте его и скопируйте идентификаторы из экспортированного файла.

    Цвет¶

    Поле Тип Обязательно Описание
    channel строка да body, roof, interior, trim, chassis, wheels или powertrain.
    value строка да #RRGGBB или #RRGGBBAA, в шестнадцатеричном формате.
    finish целое число нет Вид окраски в виде числа: 0 — обычная, 1 — металлик, 2 — матовая, 3 — перламутровая, 4 — с блёстками, 5 — хромированная. Для обычной окраски поле можно опустить.

    Только для body, roof, trim и wheels можно задать вид окраски, отличный от обычного. Для других видов окраски также нужны соответствующие исследования окраски в компании.

    Примечание

    В файле модели вид окраски хранится как число. В файле ливреи он хранится как название. В обоих случаях используется один список видов окраски.

    Схема¶

    Поле Тип Обязательно Описание
    id строка нет Идентификатор схемы внутри модели. Первая схема экспортированного файла — default; в ней повторяются цвета по умолчанию.
    name строка нет Название схемы.
    colors массив цветов да Цвета схемы.

    Для нескольких цветовых схем нужны исследования цветовых схем в компании игрока.

    Комплект¶

    Поле Тип Обязательно Описание
    id строка да Идентификатор комплекта.
    version целое число да Версия комплекта: 1 или выше.
    kind целое число да 0 — двигатель, 1 — броня, 2 — вооружение.
    parts массив деталей да Добавляемые или заменяемые детали.
    removals массив строк нет Категории деталей, которые удаляются.

    Что проверяет игра¶

    При чтении папки модов игра проверяет заголовок, поле id и наличие хотя бы одной записи в parts.

    Когда файл выбран в разделе Импортировать модель, на странице «Проекты» показывается такой же предпросмотр, как для вставленного проекта, а также выполняются остальные проверки:

    • все детали существуют в каталоге и совместимы с соседними деталями,
    • для каждого цвета указан известный канал и допустимое значение,
    • каждый комплект подходит для автомобиля.

    В предпросмотре также перечислены детали, ещё не открытые для вашей компании (для них нужны исследования или более поздняя эпоха). Если файл не проходит эти проверки, показывается то же сообщение, что и для вставленного проекта, который не прошёл те же проверки.

    Советы¶

    • Имя файла можно выбрать самостоятельно. В списке импорта файлы показаны по имени без расширения.
    • Чтобы поделиться несколькими моделями, поместите их в один мод типа model, например в подпапку models/.
    • Команды Скопировать как текст и Вставить проект на странице «Проекты» используют похожий текстовый формат car-line-tycoon.design. Для модов используйте файлы моделей: в них есть идентификатор и общий заголовок.
