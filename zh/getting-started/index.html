    入门指南¶

    模组文件夹¶

    游戏会从电脑上的一个文件夹读取模组，该文件夹位于存档文件夹旁。

    最快的打开方式：启动游戏，在主菜单选择模组，然后按打开模组文件夹。如果文件夹尚不存在，游戏会创建它，然后用文件浏览器打开。

    你也可以自行查找：

    系统 模组文件夹
    Windows %USERPROFILE%\AppData\LocalLow\DefaultCompany\Car Line Tycoon\Mods
    macOS ~/Library/Application Support/DefaultCompany/Car Line Tycoon/Mods
    Linux ~/.config/unity3d/DefaultCompany/Car Line Tycoon/Mods

    模组的结构¶

    游戏接受模组文件夹中的三种模组结构。

    带有清单文件的模组文件夹。这是推荐的结构。文件夹名称就是模组的 ID，mod.json用于描述模组（参见清单文件）：

    Mods/
  harbour_cars/
    mod.json
    models/
      harbour_coupe.clt-model.json
      harbour_van.clt-model.json

    不带清单文件的文件夹。游戏会将其中的所有模组文件作为一个以该文件夹命名的合集读取。文件夹名称必须是有效 ID。

    单个文件。将类似 harbour_blue.clt-livery.json 的文件直接放入 Mods/，该文件本身就是一个模组。其 ID 是文件名中 .clt- 之前的部分。

    以下规则适用于所有结构：

    • ID 使用小写字母、数字和下划线，以字母开头，长度为 3 至 41 个字符。
    • 游戏会查找模组文件夹下最多三层子文件夹中的模组文件。你可以将文件整理到 models/ 或 layouts/ 等子文件夹中。
    • 文件扩展名用于识别文件类型：.clt-model.json、.clt-livery.json、.clt-layout.json、.clt-scenario.json 或 .clt-lang.json。其他文件会被忽略。
    • 符号链接和目录联接会被跳过。
    • exports 文件夹归游戏所有：从游戏导出的文件会放在这里。这些文件会显示在导入列表中，模组页面不会列出此文件夹。

    模组页面¶

    在主菜单中选择模组。每个模组都会显示一行信息，包括：

    • 用于启用或停用模组的开关，
    • 模组名称（清单文件提供对应语言时会显示该语言的名称），
    • 版本、作者和类型，
    • 出现问题时显示红色边框和红色警告行（参见故障排查）。

    每次打开主菜单时，游戏都会读取模组文件夹。修改文件后，按重新加载即可重新读取。模组按英文名称的字母顺序排列。

    新模组默认处于启用状态。游戏会将你的选择保存在模组文件夹旁边的 mods.json 中。

    游戏如何使用模组¶

    模组处于启用状态且没有警告时即为活动模组。活动模组会出现在游戏内相应页面中：

    类型 游戏中的位置
    车型 设计方案页面：导入车型会列出车型文件；选择文件可查看与粘贴设计相同的预览，然后将其导入为新车型。车型详情中的导出车型会将车型写入 exports/<name>.clt-model.json。
    涂装 设计工作室的颜色方案：导入涂装会将文件添加为新的颜色方案。需要先完成颜色方案研究。
    布局 建造 → 场地：导入布局会建造文件中的墙壁、区域和对象；导出布局会保存当前场地打开楼层的布局。
    场景 新游戏 → 自由经营：场景选择器会在官方场景之后列出活动模组中的场景，并显示模组名称。
    语言 选项 → 语言以及主菜单的语言列表中会显示语言模组及其覆盖文本的比例。目前仅限开发版。

    开始或加载游戏时，游戏会将活动模组的 ID、版本、类型及其文件哈希写入存档。存档列表会用含模组标记此类存档，暂停菜单会显示已启用模组：N。即使之后移除了存档曾使用的模组，仍然可以加载该存档。

    成就¶

    车型、涂装、布局和语言不会影响成就。

    模组场景遵循所有自由经营开局的规则：如果以简单难度开始、固定启动资金达到 100,000 美元或以上，或已就绪的装配生产线超过一条，游戏会将其标记为辅助模式，且不会获得成就。

    版本与兼容性¶

    每个模组文件都以三个字段开头：

    • format：文件类型，例如 car-line-tycoon.livery。
    • formatVersion：该格式的版本。目前所有格式均为 1。
    • gameVersion：生成该文件的游戏版本。游戏会忽略内容文件中的此字段。

    游戏会读取自身格式版本及更早版本的文件。文件的 formatVersion 版本较新时，会显示警告需要更新的游戏版本。

    在 mod.json 文件中，gameVersion有独立含义：模组所需的最低游戏版本，可写为 "0.6.1" 或 ">=0.6.1"。游戏版本较旧时，模组会显示相同警告，游戏也不会使用它。

    游戏会忽略不认识的字段。你可以在文件中添加自定义备注作为额外字段；如果后续版本的文件只增加字段，仍然可以加载。

    游戏版本 可读取的内容
    0.6.0 五种格式和 mod.json、模组页面、模组提供的场景
    0.6.1 及之后版本 车型、涂装和布局的导入与导出；开发版支持语言模组

    详情请参阅更新日志。
