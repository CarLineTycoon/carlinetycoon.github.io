    Getting started¶

    The Mods folder¶

    The game reads mods from one folder on your computer, next to your saves.

    The quickest way to open it: start the game, choose Mods in the main menu, then press Open mod folder. The game creates the folder if it does not exist yet and opens it in your file browser.

    You can also find it yourself:

    System Mods folder
    Windows %USERPROFILE%\AppData\LocalLow\DefaultCompany\Car Line Tycoon\Mods
    macOS ~/Library/Application Support/DefaultCompany/Car Line Tycoon/Mods
    Linux ~/.config/unity3d/DefaultCompany/Car Line Tycoon/Mods

    What a mod looks like¶

    The game accepts three shapes of mod inside the Mods folder.

    A mod folder with a manifest. This is the recommended shape. The folder name is the mod's id, and mod.json describes the mod (see Manifest):

    Mods/
  harbour_cars/
    mod.json
    models/
      harbour_coupe.clt-model.json
      harbour_van.clt-model.json

    A folder without a manifest. The game reads every mod file inside it as a pack named after the folder. The folder name must be a valid id.

    A single file. A file such as harbour_blue.clt-livery.json placed straight in Mods/ is a mod of its own. Its id is the part of the file name before .clt-.

    A few rules apply to every shape:

    • Ids use lower-case letters, digits and underscores, start with a letter and are 3 to 41 characters long.
    • The game finds mod files up to three folder levels below the mod folder. You can organise them in subfolders such as models/ or layouts/.
    • The file extension tells the game what a file is: .clt-model.json, .clt-livery.json, .clt-layout.json, .clt-scenario.json or .clt-lang.json. Other files are left alone.
    • Symbolic links and junctions are skipped.
    • The exports folder belongs to the game: files you export from the game go there. Its files show up in the import lists, and the Mods page leaves it out.

    The Mods page¶

    Choose Mods in the main menu. Every mod has a row with:

    • a switch to turn it on or off,
    • its name (in your language when the manifest has it),
    • its version, its authors and its type,
    • a red border and a red warning line when something is wrong (see Troubleshooting).

    The game reads the Mods folder each time the main menu opens. After you change a file, press Reload to read it again. Mods are listed in alphabetical order of their English name.

    A new mod starts switched on. The game keeps your choices in mods.json, next to the Mods folder.

    How the game uses mods¶

    A mod is active when it is switched on and has no warning. Active mods show up in the game's own pages:

    Type In the game
    Car model Models page: Import model lists the model files; pick one to see the same preview as a pasted design, then import it as a new model. Export model in a model's details writes exports/<name>.clt-model.json.
    Livery Design studio, Colour schemes: Import livery adds the file as a new colour scheme. It needs the colour schemes research.
    Layout Build → Sites: Import layout builds the file's walls, areas and objects; Export layout saves the open floor of the open site.
    Scenario New game → Free play: the Scenario selector lists the scenarios of active mods after the official ones, with the mod's name.
    Language Options → Language and the language list of the main menu, with the share of texts the language covers. Development builds only for now.

    When you start or load a game, the game writes the active mods into the save: id, version, type and a hash of their files. The saves list marks such saves with mods, and the pause menu shows Active mods: N. A save that used a mod you later removed still loads.

    Achievements¶

    Car models, liveries, layouts and languages do not affect achievements.

    A scenario from a mod follows the rule every Free play start follows: the game counts as assisted, and earns no achievements, when it starts on Easy, with a fixed amount of $100,000 or more, or with more than one ready assembly line.

    Versions and compatibility¶

    Every mod file starts with three fields:

    • format: the kind of file, for example car-line-tycoon.livery.
    • formatVersion: the version of that format. Every format is at version 1 today.
    • gameVersion: the game version that wrote the file. The game ignores it in content files.

    The game reads files of its own format version and older ones. A file with a newer formatVersion gets the warning Requires a newer game version.

    In mod.json, gameVersion has its own meaning: the oldest game version the mod needs, written as "0.6.1" or ">=0.6.1". When the game is older, the mod gets the same warning and the game does not use it.

    Fields the game does not know are ignored. You can add your own notes to a file as extra fields, and a file written for a later version still loads when it only adds fields.

    Game version What it reads
    0.6.0 The five formats and mod.json, the Mods page, scenarios from mods
    0.6.1 and later Import and export of models, liveries and layouts; language mods in development builds

    The changelog has the details.
